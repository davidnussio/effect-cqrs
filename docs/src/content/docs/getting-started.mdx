## Install

```bash
pnpm add effect-cqrs effect
```

It needs Node 24 or later and Effect 4. To store events in SQLite or PostgreSQL, add
that database's `effect/sql` driver too:

```bash
pnpm add @effect/sql-sqlite-node
pnpm add @effect/sql-pg
```

Everything is exported from `effect-cqrs`, and each module also has its own path, such
as `effect-cqrs/ViewModel`.

## Try the examples

The examples live in the repository, where they import the TypeScript sources directly.

<Steps>

1. Clone the repository and install the dependencies. It needs pnpm.

   ```bash
   git clone https://github.com/davidnussio/effect-cqrs.git
   cd effect-cqrs
   pnpm install
   ```

2. Run the tests.

   ```bash
   pnpm test
   ```

3. Run the todo example. It is the moleculer-cqrs README walkthrough as a program, on an
   in-memory SQLite database.

   ```bash
   pnpm example
   ```

4. Serve the bank demo at http://localhost:5173.

   ```bash
   pnpm ui
   ```

</Steps>

## What's where

<FileTree>

- src/
  - Aggregate.ts defines aggregates
  - AggregateService.ts runs commands and reads state and history
  - ViewModel.ts projects events into read models
  - Checkpoints.ts remembers how far each view model has read
  - EventStore.ts the log, and the store in memory
  - SqliteEventStore.ts
  - PostgresEventStore.ts
  - Fixture.ts tests an aggregate in isolation
- examples/
  - todo/ the moleculer-cqrs walkthrough
  - bank-ui/ the bank demo, in the browser
- bench/ performance and stress tests, and their report
- test/

</FileTree>
