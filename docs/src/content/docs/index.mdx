<Aside type="caution" title="A trial port">
This is an experiment that ports [moleculer-cqrs](https://github.com/davidnussio/moleculer-cqrs),
a CQRS and event sourcing module for Moleculer written in 2019, to
[Effect](https://effect.website) v4. It isn't published to npm, and the API may change.

## How a command flows

1. A command arrives, as a typed call or as JSON, and its payload is validated against
   its schema.
2. The service loads the aggregate's state from its events, or from memory when it saw
   the aggregate recently, and the handler decides which events happened.
3. The events are appended to the store, but only if nobody else wrote to that
   aggregate since the state was loaded.
4. Each view model reads the new events from its own checkpoint and updates its read
   model. A client that needs its own write waits with `caughtUp`.

The [bank demo](demo/) shows these stages one at a time.
