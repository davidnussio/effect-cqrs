## CQRS with effect-cqrs

A series in five parts, November 2026. We build a small lending library, where members
borrow books and bring them back, from the first event to a saga, tests and a database.
Every snippet comes from
[`examples/blog`](https://github.com/davidnussio/effect-cqrs/tree/main/examples/blog),
whose tests run it.
