We build a shop: customers place **orders**, and a **saga** holds the **stock** for each
one and gives the customer 15 seconds to pay. It confirms a paid order, and rejects one that
is out of stock or not paid in time. Every snippet comes from
[the full example](#the-full-example), which you can run with `pnpm tutorial`.

## 5. A saga

A saga reacts to an event and runs commands on other aggregates. The trigger starts a
workflow for each `OrderPlaced`, and each command in it is a step the engine remembers:

<Code code={region(shop, "saga")} lang="ts" title={file} />

The run waits for the payment in the middle of the process:

- `DurableDeferred.token` names this run's `Payment`. The saga stores it in
  `PaymentRequested`, the order copies it into `OrderPaid`, and the trigger hands it to
  `DurableDeferred.succeed`, which wakes the run.
- `DurableDeferred.raceAll` races the payment against `DurableClock.sleep` and saves the
  winner, so a replay takes the same branch.
- When the time runs out, the saga rejects the order and releases the stock. If the
  customer paid just before, the order refuses with `OrderAlreadyPaid`, and the saga confirms
  it instead. Each aggregate decides alone, so the order settles any race between the two.

`DurableClock.sleep` keeps a minute or less in memory. A longer timeout becomes a clock the
engine schedules, which a durable engine keeps across restarts.

## 7. Metadata

Metadata is what a command carries beside its payload: the app version, the user, the
channel. `Metadata.layer` above sets the version for every command, and
`Metadata.withMetadata` adds to it for one call:

<Code code={region(shop, "metadata")} lang="ts" title={file} />

```txt
order-2 history [
  { type: 'OrderPlaced', metadata: { appVersion: '1.0.0', userId: 'bob', channel: 'mobile' } },
  { type: 'OrderRejected', metadata: { appVersion: '1.0.0' } }
]
```

The saga's `OrderRejected` doesn't inherit `userId`: a reaction records its own metadata.

## 9. Metrics

Every aggregate service records metrics with Effect's `Metric` module. Read them with
`Metric.snapshot`, or send them to an exporter:

<Code code={region(shop, "metrics")} lang="ts" title={file} />

```txt
order.place timings [
  { outcome: 'success', count: 2, totalMs: 0.806 },
  { outcome: 'OrderAlreadyPlaced', count: 1, totalMs: 0.273 }
]
```
